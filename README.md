OVERBOLT | NO BS
Application de suivi de musculation - Progressive Web App
À propos
OVERBOLT est une application web progressive (PWA) de suivi d'entraînement en musculation, pensée pour être simple, rapide et sans fioritures. Toutes les données sont stockées localement sur l'appareil.
Fonctionnalités
Suivi des séances, exercices et séries (charge, répétitions, temps de repos)
Historique complet semaine par semaine, avec calendrier de suivi
Fonctionne 100% hors ligne une fois chargée
Installable sur l'écran d'accueil (iOS et Android)
Interface multilingue (16 langues)
Export/import des données au format JSON
Technique
Application en un seul fichier HTML autonome (HTML/CSS/JS), avec service worker pour le fonctionnement hors ligne.
